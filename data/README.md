# Data

The raw datasets are **not** redistributed in this repository. Each one is available from its provider under the provider's own terms. Place the files as described below; the loaders read them by path.

## Transit timetables (Kujala et al. 2018)

- Source: Zenodo record 1186215, version 1.2.
- Download: `bash experiments/fetch_transit.sh [city ...]`. The default cities are `turku grenoble adelaide kuopio`. The script stores `network_temporal_day.csv` for each city under `data/raw/transit/<city>/`.
- Inventory of the local files (stdlib only, JSON on stdout): `python3 -I experiments/transit_manifest.py`.

## Contact data

- SocioPatterns contact data sets (Fournet et al., Mastrandrea et al., Stehle et al., Vanhems et al.).
- Copenhagen Networks Study (Sapiezynski et al. 2019): `bt_symmetric.csv`, `calls.csv`, `sms.csv`.
- Loaders: `experiments/datasets.py` (`sociopatterns`, `copenhagen`).

## Generated benchmarks

The benchmark instances are generated by the scripts in `experiments/` from the raw data above and from fixed random seeds. The generators are `experiments/census.py`, `experiments/datasets.py`, and `experiments/family.py`. The instances themselves are not stored in this repository.
